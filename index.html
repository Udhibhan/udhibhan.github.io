Projects

Satellite Ground Station Tracker

The existing AZ/EL tracker codebase was tied to old motion controller hardware and hard to extend. I'm rebuilding it around a hardware abstraction layer so the actuator backend can be swapped, driving new eRob actuators over CANopen. Python, CANopen, TLE-based pass scheduling.

Quantum Control Crate Debugging

Worked on a Sinara/ARTIQ quantum control crate at Atomionics — tracing RTIO timing collisions across a Kasli, Urukul DDS, and Zotino DAC, and getting the full software pipeline running end to end without touching persistent device config. ARTIQ, RTIO, embedded timing.

CAN Bus Thermocouple Monitoring

Built a multi-node monitoring system that reads thermocouple data over CAN from several STM32 nodes and logs it on a Raspberry Pi, with DIP-switch-based node addressing so nodes can be added without reflashing IDs. MCP9604, STM32, CAN bus.
